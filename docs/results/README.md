# Benchmark results

Each folder is one run of `bench/run_m2.sh` (procedure: `bench/README.md`). Every number in these files
sits next to its label (side, where, mode, threads, cap); a number quoted without its labels is not a
result. A run whose parity gates fail publishes nothing, so every folder here passed parity.

## 2026-10-13-500k

ChEMBL 37, 500,000 requested rows (499,997 loaded; 3 failed RDKit canonicalization in the slice builder, 2 more
rejected by the cartridge and excluded from both sides' counts).

| | |
|---|---|
| Code under test | git `ed56185` (cartridge and VM runs; the host run records `1da1dbc`, which differs only in `.gitignore` and a backlog note) |
| Docker VM | 6 CPUs, 16746352640 bytes (15.6 GiB), from `docker info` on the host |
| Image architecture | arm64 (cartridge `informaticsmatters/rdkit-cartridge-debian:Release_2025_03_3` and the `bench` image), from `docker image inspect` on the host |
| Host | macOS 27.0, arm64; Python 3.13.15; RDKit 2025.03.3 on both sides |
| Cartridge settings | shared_buffers 4GB, maintenance_work_mem 2GB, work_mem 256MB, morgan_fp_size 2048, do_chiral_sss off |

The two `molseal_vm_*` files show `unavailable` for git SHA, image architecture and VM size: the bench
container has neither `git` nor `docker`. The values above were read from the host after the run.

| File | What it is |
|---|---|
| `gate_10k.json` | 10k gate: load stats, absence check against the DB and a real `pg_dump`, leak report; `ok` must be true |
| `slice_500000.meta.json` | Slice builder counts (requested, loaded, skipped) |
| `queries_500000.json` | Seeded query set: 72 substructure (BRICS fragments, functional-group and ring SMARTS), 50 similarity |
| `load_molseal_500000.json` | molseal host-native load: rows, seconds, rows/s, peak RSS (not comparable to the cartridge load) |
| `load_cartridge_500000.json` | Cartridge load: insert, fingerprint update and both GiST build times; rejected rows |
| `parity_500000.json` | The four parity gates: fingerprint bytes (100 sampled), substructure counts (72), id sets (42 with <= 10k hits), similarity ids and scores (50) |
| `timings_500000_<side>_<where>_<mode>.json` | Per-query medians with labels, plus run metadata (peak RSS, snapshot size, cold snapshot load, buffers before the run) |
| `timings_500000.md` | p50 and p95 across queries for every label combination, generated by `run_bench --report` |
| `leak_500000.json` | What the ciphertext size class says about molecule size |
| `mem_500000.log` | `docker stats` every ~30 s for the whole run. Samples 15:50:13 to 15:54:04 belong to a discarded cartridge load (stale volume, reset and reloaded); every other window is the published run |
